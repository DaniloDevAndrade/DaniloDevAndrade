## 🚀 Sobre mim

Tenho 26 Anos e sou natural de São Paulo, Atualmente estou cursando Engenharia da Computação pela UNIVESP. Sou um grande intuciasta de tecnologia e programação desde criança e hoje sou desenvolvedor Full Stack e trabalho como freelancer, criando sites e aplicativos para clientes.

- 💻 Na web: Next.js, TypeScript e Tailwind CSS
- ⚙️ No back-end: Node.js com NestJS e Fastify
- 📱 No mobile: React Native com Expo
- ✨ Gosto de interface com movimento: animações com GSAP e scroll suave com Lenis
- 🌱 No caminho de júnior para pleno, um estudo de cada vez

## 💼 O que ando construindo

🔒 Trabalho de cliente fica em repositório privado, então em vez de links, um resumo do que passa pelo meu editor:

**🌐 Sites e landing pages** · Páginas institucionais e de produto em Next.js com TypeScript e Tailwind, animação com GSAP, scroll suave com Lenis e deploy na Netlify.

**📱 Aplicativo mobile** · App em React Native + Expo com navegação por expo-router, login com biometria, armazenamento seguro e formulários com react-hook-form, gerando builds Android pela EAS.

**🏢 Sistemas empresariais** · Sistemas de gestão sob medida para o dia a dia de empresas, com API em NestJS e Fastify, painéis em React e deploy com Docker.

**☁️ SaaS** · Produtos em modelo de assinatura, construídos do back-end à interface, prontos para crescer junto com o negócio.
